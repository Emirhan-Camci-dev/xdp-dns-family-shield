# Contributing to EdgeShield-DNS

Thank you for your interest in contributing! 

## Open-Core Model

Please note that this project operates under an Open-Core model.
- We gladly accept Pull Requests and issues for the `community/` directory.
- The `enterprise/` directory is closed to external contributions unless specifically requested.

## Submitting Pull Requests

1. Fork the repository.
2. Create a feature branch.
3. Ensure your code passes all tests (`make test`).
4. Submit your PR targeting the `main` branch.
