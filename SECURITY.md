# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.
Instead, email the author at `byemir@live.com` with the details of the vulnerability.
We will respond within 48 hours to acknowledge the report and provide a timeline for a patch.
